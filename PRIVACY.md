# Privacy

Phoenix Engine v1.1 is designed around browser-local processing.

## Local Files

Local audio files are selected by the user and processed in the browser. Phoenix Engine does not require uploading local audio files to a Phoenix Engine server for Scena preview, Finalis playback, WAV export, or browser-local video export.

## Third-Party URL Analysis

Public YouTube URL analysis is disabled in v1.1. The public app does not call the previously audited Cobalt API for YouTube reference analysis.

## Browser Storage

Phoenix Engine may use browser storage for presets, recent project metadata, and local configuration. Clearing site data may remove these saved settings.

## Analytics

Phoenix Engine uses Google Analytics 4 and Microsoft Clarity only after analytics consent is granted.

These services help understand general traffic, browser/device environments, and interaction patterns so the public application can be improved.

Phoenix Engine does not intentionally send audio, artwork, project data, file names, analysis results, or local file paths to these analytics services.

Analytics consent can be allowed, rejected, or changed from the in-app **Utilities > Privacy Settings** panel in either Scena or Finalis.

## GitHub Issues and Discussions

GitHub Issues and Discussions are public. Do not post private audio files, personal information, credentials, unpublished works, or sensitive security details in public GitHub threads.
