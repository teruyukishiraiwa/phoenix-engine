# Security Policy

## Supported Version

| Version | Status |
|---------|--------|
| v1.0.x | Supported after public release |

## Reporting a Vulnerability

Do not publish vulnerability details, credentials, private files, or user audio content in public GitHub Issues or Discussions.

If GitHub Security Advisories are enabled for this repository, use a private security advisory for vulnerability reports.

If a private GitHub advisory is not available, contact:

```text
t.shiraiwa@teruyukishiraiwa.art
```

Please include **"Phoenix Engine Security"** in the subject or opening message.

You can also refer to the contact information on the creator website:

<https://teruyukishiraiwa.art/>

## Scope

Security reports may include:

- Unexpected network transmission.
- Incorrect handling of local files.
- Cross-origin or deployment header issues.
- Public asset integrity mismatch.
- Third-party runtime or license/source notice issues.

Application source code is proprietary and is not distributed through this repository.
