# Support

For Phoenix Engine support after the public release, use GitHub Issues in this repository for public bug reports, support requests, and feature requests.

Official site: <https://phxengine.static.jp/>  
Creator website: <https://teruyukishiraiwa.art/>  
Direct contact: <t.shiraiwa@teruyukishiraiwa.art>

## Public Support

Use GitHub Issues for:

- Bug reports.
- Reproducible playback, export, or browser compatibility issues.
- Documentation corrections.
- Feature requests that can be discussed publicly.

If GitHub Discussions are enabled, use Discussions for general usage questions, impressions, and non-bug conversations.

GitHub does not provide a general private direct-message feature. Do not use public Issues for private or sensitive information.

## Before Filing an Issue

Please include:

- Browser and version.
- Operating system.
- Whether hardware acceleration is enabled.
- Which surface was affected: Scena or Finalis.
- Steps to reproduce.
- Whether the issue occurs with a short local audio file.
- Console errors if available.

## Do Not Post Publicly

Do not post the following in public Issues or Discussions:

- Private audio files or unpublished works.
- Personal information.
- Passwords, tokens, server paths, or credentials.
- Security vulnerability details that could enable abuse.
- Rights-related or contractual matters.

## Unsupported Requests

This repository does not provide Phoenix Engine application source code.

Please do not file issues requesting source publication, build instructions for the private application, or changes that require access to proprietary implementation details.
