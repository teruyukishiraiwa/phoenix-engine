# About Phoenix Engine

Phoenix Engine is created by **Teruyuki Shiraiwa / 白岩晃行**.

Official website: <https://teruyukishiraiwa.art/>  
Phoenix Engine: <https://phxengine.static.jp/>

## Creative Context

Phoenix Engine originated from the creative context of **"Phoenix"**, a musical work by Teruyuki Shiraiwa. The application extends that artistic context into a browser-based environment for motion artwork and precision audio finishing.

The project is built around two integrated surfaces:

- **Scena**: motion artwork, visual design, scene preview, and video export.
- **Finalis**: local audio mastering, metering, reference comparison, WAV export, and final export analysis.
